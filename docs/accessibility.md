# Accessibility

Phase 1 includes semantic landmarks, skip link, keyboard-focus styles, accessible buttons and links, mobile menu Escape handling, Quick View dialog Escape handling, SVG descriptions, `aria-pressed` filters, and reduced-motion CSS.

External links use safe `rel` handling. The public portfolio does not depend on the generator API, GitHub API, AI server, or remote CMS.

Phase 2 preserves semantic text while animating wrappers and SVG attributes. Reduced-motion mode disables Lenis, cursor, pulses, pinned philosophy behavior, and nonessential movement while keeping content visible immediately. Hover effects have focus-visible equivalents and the custom cursor never replaces keyboard focus.
