# Responsive Design

The portfolio uses one responsive component tree with CSS grid changes at tablet and mobile breakpoints.

Minimum reviewed targets include desktop, tablet, and narrow mobile widths. The layout prevents horizontal overflow, wraps project technologies, stacks project panels, switches timelines to vertical, and uses a full-screen mobile menu.

Mobile tap targets are at least 44px where interactive controls are used.

Motion is responsive. Desktop enables Lenis, ScrollTrigger reveals, SVG interaction, Motion layout transitions, and the custom cursor only on precise pointers. Tablet uses a balanced mode without dense cursor assumptions. Mobile keeps native scrolling, disables cursor and magnetic effects, avoids pinned sections, and uses simpler menu/dialog transitions.
