# muneeb-systems

Minimal foundation for **MUNEEB.SYSTEMS**: a public Next.js portfolio plus a private local generator API/UI.

```bash
pnpm install
pnpm dev
```

Local apps:

- Portfolio: `http://localhost:3000`
- Generator API: `http://localhost:4000`
- Generator UI: `http://localhost:4173`

Docker:

```bash
pnpm docker:build
pnpm docker:up
```
